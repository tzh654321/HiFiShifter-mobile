## 2. 方案 P 步骤（现行首选，全流程已跑通）

### P-0 环境自检

```powershell
. D:\hs-desktop-build\env-vs.ps1
```
会打印一张自检表（`cl.exe` / `cmake.exe` / `ninja.exe` / `cargo.exe` / `node.exe` / `rc.exe` / `tauri.cmd`
各自解析到的路径）+ MSVC/SDK 版本 + Generator。**任何一行显示 `!! 缺失` 就先修环境，别急着构建。**

要点：`env-vs.ps1` 做四件事 ——
1. 跑 `vcvars64.bat` 把它的环境**导入当前 PowerShell**（INCLUDE/LIB/VCTargetsPath/WindowsSdkDir 一次到位，
   不再手写 MSVC 版本号，修 VS 后版本变了也不用改脚本）；
2. 把 `node / tauri / cmake / ninja / SDK bin` 前置进 PATH，并**剔除任何 `portablegit` / `mingw64` / `msys` 路径**；
3. 设 `CARGO_TARGET_DIR` / `ORT_CACHE_DIR` / `TMP` / `TEMP` 全落 D 盘；
4. 设 `CMAKE_GENERATOR=Ninja`、`CC=cl.exe`、`CXX=cl.exe`、`CARGO_BUILD_JOBS=1`。

> ⚠️ `env-vs.ps1` **故意不设** `$ErrorActionPreference='Stop'`：dot-source 会污染调用方，
> 把 cmake 写到 stderr 的正常 warning 变成终止错误。它自己也只设 `Continue`。
> ⚠️ PowerShell 默认禁跑脚本，调用前需 `Set-ExecutionPolicy -Scope Process Bypass -Force`
> （进程级，不需要管理员；`build-desktop.ps1` 已内置）。

## 3. 根因判定：为什么 Git Bash 里一定崩（本轮才查清）

**证据链**：

| # | 实验 | 结果 |
| :-: | :--- | :--- |
| 1 | 在 PowerShell 里直接跑 `…\2022\Community\MSBuild\Current\Bin\amd64\MSBuild.exe -version` | ✅ 正常输出 `17.14.60+43b635718` —— **MSBuild 没坏** |
| 2 | 在 PowerShell + `vcvars64` + `-G Ninja` 里跑 soundtouch 的 `cmake -S … -B …` | ✅ `Configuring done` / `Generating done`，**MSBuild 根本没被调用** |
| 3 | 同样命令放回 Git Bash（沿用 `env-vs.sh`） | ❌ `Failed to run MSBuild command … to get the value of VCTargetsPath: Access violation` |

**判定**：`Access violation` 不是 MSBuild 自身缺陷，而是**进程加载到了 MSYS 的 DLL**。
Git Bash 启动的进程树把 `PortableGit\mingw64\bin` 之类塞在 PATH 前面，MSBuild 派生时被"劫持"。
`env-vs.sh` 第 33-38 行已经在往这个方向猜（只剔了 `portablegit`/`mingw64`，**漏了 `/usr/bin`**），
但更省事、也更彻底的做法是**根本不在 Git Bash 里构建**。

**同时**：即使用 Ninja 生成器，也**不要**让它退化回 Visual Studio 生成器 ——
那条路会重新要求 CMake 调 MSBuild 查询 `VCTargetsPath`。所以 `CMAKE_GENERATOR=Ninja` 必须在环境里钉死。

## 4. 关键原则（别再踩）

1. **必须用 `tauri build`，不能用 `cargo build --release`** —— 前端资源由 tauri CLI 嵌入；
   纯 cargo 构建的 exe 会去连 `devUrl`（`http://localhost:5173`）而白屏。
2. **构建源必须是干净上游**（`git archive HEAD` 导出）——仓库工作树常年有移动端半成品
   （实测工作树与构建源有 60 个源文件不同、1677 个文件仅工作树有，绝大多数是 `gen\android` 构建产物）。
3. **绝不在 Git Bash 里构建** —— 见 §3。
4. 所有临时/缓存目录放 **D 盘**（C 盘长期只剩 1 GB 量级）。
