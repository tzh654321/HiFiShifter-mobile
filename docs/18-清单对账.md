## 状态定义（严格五类，不自创）

| 状态 | 含义 | 证据门槛 |
| :--- | :--- | :--- |
| `✅脚本` | 有**设备/模拟器上跑过的探针脚本**判定通过 | 必须写出**脚本名** + **结论数字**（如 `7/7`） |
| `✅口述` | 用户明确说过"可以了/好了/验收通过" | 写出在哪篇文档看到这句，尽量给引用 |
| `⏭不做` | 用户明确说不用做 / 暂缓（"先加todo"、"暂时不用管"、被点名"不做"） | 写出用户口径出处 |
| `⬜未做` | 没有任何证据表明做完 | —— |
| `⚠️待确认` | 看起来做了但**证据不足**（实现痕迹在、但无脚本判据、或与用户口径有偏差） | 宁可标这个，也不猜 |

> **关于 `⚠️待确认` 偏多**：这是**故意**的。本项目里"实现痕迹"极多（补丁 `0005` 里成百上千处 UI 改动），
