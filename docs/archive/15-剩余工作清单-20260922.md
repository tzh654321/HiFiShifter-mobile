## A. 功能缺口（用户能感知）

### A1. 参数界面的拍数栏点不动 🔴 优先

- **现象**：手机上在**参数面板**里点拍数栏，播放红线不动。时间线那边是好的。
- **根因**：上游标尺的 `onMouseDown` 首行有 `isLegacyMouseEventFromStylus()` 守卫，**对 touch 也返回 true**，
  所以触摸走不到 seek。已加的 pointer 专用路径 `bindRulerTouchSeek` 目前**只挂在 `TimelinePanel.tsx`**
  （`components/layout/TimelinePanel.tsx:660` / `:729`），`PianoRollPanel` 没有。
- **算做完**：参数面板拍数栏单指点击 → 红线移动；CDP 断言（`touch-drive.mjs tap` + 读 playhead 位置）。

### A2. 移动端导不出工程（SAF v2）

- **现象**：`pick_folder` / `save_file` 返回 `None`（v1 只做了 `pick_file`/`pick_files`）。
  于是「导出到自选目录」这条路在 Android 上是断的。
- **落点**：`platform/saf.rs`（JNI 回调 + mpsc）、`HifishifterFs.kt`、`frontend/src/services/invoke.ts`。
- **要做**：`pick_folder` 走 tree URI 懒物化；`save_file` 要定义"写完了"的时点 + `commit_export`。
- **算做完**：真机上能把工程存进用户选的目录，且能再读回来。

### A3. 移动端没有 i18n

- **现象**：切成英/日/韩，**移动端界面纹丝不动**（桌面端会跟着变）。
- **落点**：`components/mobile/MobileBottomBar.tsx`（约 58 处硬编码中文）、`MobileTopBar.tsx`、`BottomTabs.tsx`。
  键早就在 `src/i18n/*.ts`（5 个语种）里备好了。
- **算做完**：三语切换后移动端无中文残留；`grep` 中文在 mobile 目录为 0。

### A4. 平板密排工具栏的触摸目标（**设计取舍，等你定**）

- **现象**：平板审计长期报 `tooSmall 59`，明细全是 ActionBar 密排控件：图标按钮**命中 34×40**、
  输入框/下拉 h=37。

- **`docs/04 §13.3`（第二处）有三个选项**，选一个就能动手。

## B. 技术债（用户看不见，但会咬人）

### B1. arm64 的 APK 打不出来 🕳️

- **现象**：`gradle :app:compressUniversalDebugAssets` 对 **arm64 变体稳定失败**，x86_64 正常。
  失败信息只有一句 `> <tmpdir>/<uuid>.tmp`。
- **已排除**：TEMP 位置（`D:\Temp` 与 `C:\hs-temp` 都失败）、assets 目录（无符号链接、无 0 字节文件）、
  空间（C 3.7G / D 90G）。那个 `.tmp` 恒为 **261 B 高熵数据**，与 9-21 那次**逐字节相同**。
- **当前的绕行**（已实测可用，见 §3）：`scripts/swap-so-in-apk.py` 换 `.so` + `zipalign` + `apksigner`。
- **为什么值得查**：只要原生层（Rust）一改，绕行方案就不成立了 —— 那时必须能完整构建 arm64。
- **算查完**：`bash scripts/build-apk.sh arm64-v8a` 一路到 `✅ 构建完成`。

## 3. 附：arm64 包绕行流程（B1 的当前解法，已实测）

前提：**原生层没动、只改了前端** —— 因为前端 dist 是**嵌进 `libbackend_lib.so`** 的
（Tauri 2 Android custom-protocol 模式），所以"旧 APK 外壳 + 新 `.so`"与完整重建等价。

```bash
# ① cargo 是能成功的，产物在这里：
#    D:/code/HiFiShifter/hfshifter-target-upstream/aarch64-linux-android/debug/libbackend_lib.so

# ② 换库（原生库写 STORED：Android 11+ extractNativeLibs=false，压缩过的 .so 装不上）
python scripts/swap-so-in-apk.py dist/hifishifter-arm64-ui6.apk D:/out/_raw.apk \
    lib/arm64-v8a/libbackend_lib.so <上面那个 so>

# ③ 对齐 + 用 debug keystore 重签（与 AGP debug 包同 key ⇒ 真机可覆盖安装）
D:/Android/Sdk/build-tools/35.0.0/zipalign.exe -f -p 4 D:/out/_raw.apk D:/out/_aligned.apk
D:/Android/Sdk/build-tools/35.0.0/apksigner.bat sign \
    --ks C:/Users/tzh/.android/debug.keystore --ks-key-alias androiddebugkey \
    --ks-pass pass:android --key-pass pass:android \
    --out D:/out/hifishifter-arm64-debug.apk D:/out/_aligned.apk

# ④ 装（真机走 push + pm install，不用 adb install）
adb -s 221deeb push D:/out/hifishifter-arm64-debug.apk /data/local/tmp/hs.apk
adb -s 221deeb shell pm install -r /data/local/tmp/hs.apk
```
