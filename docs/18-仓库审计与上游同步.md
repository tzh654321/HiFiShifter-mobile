## 审计发现

### 已在本次处理

- 补丁验证原本只检查补丁自身文件清单，可漏掉工作树修改/新增文件；扩大检查范围。
- 重放后索引存在、工作树缺失的文件原本不计失败；改为报告漂移。
- 前端/通用补丁重生成脚本原本跳过删除文件；改为从独立索引删除。
- 波形绘制存在重复嵌套的空顶点 if；随独立上游优化清理。
- 全量测试实测发现文件浏览器初始化直接读 localStorage，导致无浏览器存储环境下 10 个测试套件加载失败；添加不可用/抛错时回退，并保留可用时的用户偏好，增加 3 个回归测试。
- 首次并行测试中刻度密集采样测试超过默认 5 秒；以 2 workers、30 秒超时重跑确认，未修改刻度算法。

### 加强校验后实测发现的既有漂移

5 个补丁均可在基线完整应用（OK 5 / 跳过 0 / 失败 0），扩大检查范围后对比 123 个文件，发现以下本次未修改的后端工作树内容未被正确保存在补丁中：

- 重放缺失：`backend/src-tauri/src/storage.rs`。
- 内容不一致：`backend/src-tauri/src/commands/file_browser.rs`、`backend/src-tauri/src/commands/timeline.rs`、`backend/src-tauri/src/config.rs`。

因此全仓库重放自检结果为失败（漂移 3 / 缺失 1），不是前端测试失败。本次前端 0005 补丁重生成后未报告前端漂移。原校验范围遗漏上述路径，不能把旧脚本的“通过”视为完整复现证明。没有擅自折入这些未知来源的后端工作树修改，后续应审查语义和来源、做 Rust/Android 验证后再更新平台补丁。

### 仍需优先处理（确定问题）

1. **新克隆初始化/构建链断裂**：上游源码整棵忽略，但 README 的构建片段缺 clone、固定 checkout、依赖安装和 Android 初始化流程。`build-apk.ps1` 201–202、`build-apk.sh` 109–134、`setup-gen-android.sh` 259–266 仍依赖已经移出仓库的 `probes/m0-probe` CLI；本地对应 tauri.js 也不存在。PowerShell 入口因此不能正常构建，Bash 仅在碰巧安装全局 CLI 时可能越过。
2. **release 混用 debug 主库**：`setup-gen-android.sh` 728–752 的打包前修复任务不区分 variant，始终读取 debug/libbackend_lib.so。release 构建可能被 debug 库覆盖，必须按 variant/profile 选择路径并在缺库时失败。
3. **release APK 归档路径错误**：`build-apk.sh` 390 固定 debug APK；443–445 在找不到时跳过校验，458 仍复制该路径。需要随构建 profile 选择 APK，并禁止无包时静默越过校验。
4. **工具链写死个人机器路径**：`android-env.sh` 57–83/114、`build-apk.ps1` 43–46/106–108、`build-apk.sh` 391–395 等覆盖或写死 SDK/NDK/JDK/Python/缓存/代理环境。需尊重调用者环境并提供明确错误提示。
5. **基线与验证语义**：校验仍从当前 HEAD 播种、允许反向检查后跳过。完整验证只证明“在当前 HEAD 下可重放”，并非独立证明 HEAD 就是锁定基线；运行前应确认上述完整 SHA。后续建议提供统一锁文件和初始化脚本。

### 待专门验证的风险

- **R8/JNI**：release 开启 minify，但 Kotlin 文件系统桥未见自定义 keep 规则；Rust 按固定类名和方法名访问。应检查有效 ProGuard 规则、mapping，并做 release 真机文件导入/保存测试，不能用 debug 成功代替。
- **外部打开 ANR/缓存耗尽**：`HifishifterFs.kt` 968–984 在 Activity 回调同步物化输入，826–830 copyTo 未见大小/耗时限制。应测试超大文件及慢 content provider，并将耗时操作移出 UI 线程。
- **权限口径**：README 称不申请存储权限，生成 Manifest 实际有 MANAGE_EXTERNAL_STORAGE。若发布 Google Play，需另评估权限政策；不能简单认定为安全漏洞。
- **许可证交付**：README 声称 MIT/SoundTouch LGPL，但移动端仓库当前无独立 LICENSE/NOTICE/COPYING。需核查 APK 与源码交付义务；本次不据此认定侵权。
- **历史仓库体积**：当前树已移除原生库，但历史提交仍含约 63.3 MB ONNX Runtime 二进制。清理历史需改写 SHA，与普通同步不同，本次不做 force push 或历史改写。

对脚本和保留日志的常见凭据标识扫描未发现明确密钥，不能视为全历史无泄漏证明。
